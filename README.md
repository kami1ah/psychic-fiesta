La Fosse Hackathon

## GAME 1 - Rock, Paper, Scissors
### How to play
1. Open terminal 
2. run node.js - `node.js`
3. To start the game - `node RPS.js`
4. Once the game starts, in the terminal it prints `Enter your choice (rock/paper/scissors)?`
5. You will then write your choice: rock OR paper OR scissors
6. The randomiser picks the computer's choice
7. Then the result of the game is printed which are either: `You Win` OR `Draw` OR `You Lose`
